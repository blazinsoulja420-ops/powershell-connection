# UPAB v1.1 — Exact Relay Autopilot Release Notes

## Upgrade type

Additive upgrade from the verified UPAB v1 Local Edition baseline. The v1 executor/governance model remains authoritative; Exact Relay adds deterministic task transport and transaction orchestration.

## Added

- strict `upab.exact-relay.task.v1` task envelope;
- Windows clipboard watcher;
- one-time rotating relay nonce;
- unique task ID replay ledger;
- short task expiry window;
- repository identity and mutation HEAD pinning;
- ordered multi-operation pipeline;
- structured result package copied to clipboard;
- transaction-wide rollback for relay-created writes;
- unique per-write backups outside the repository;
- relay CLI commands and Windows helper scripts;
- migration script that preserves `local.json` and does not grant write authority.

## Preserved controls

- canonical UPGS mutation gate;
- `read_only` authority;
- exact authorized write path manifest;
- existing-file expected SHA-256 requirement;
- repository root sandbox;
- Git HEAD/state guards;
- read-only PowerShell allowlist and deny patterns;
- redacted evidence logging;
- atomic file writes.
